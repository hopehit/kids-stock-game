# 小小投资家 · 经营闯关版

给小学和初中孩子玩的理财启蒙小游戏：先开一家奶茶店当老板，再一关一关学股份、涨跌、风险分散、复利、分红、指数基金、市值、财报、市盈率、K 线等概念。

- 游戏里的公司全部是**虚构公司**，价格、财报、K 线都是**模拟数据**。
- **不是投资建议**，不推荐任何真实股票。真实的开户和交易由家长决定。交易规则类内容以交易所最新规定为准。
- 不联网、不收集任何信息；进度只保存在你自己设备的浏览器里。没有充值、抽奖、广告。
- 打开一次后会缓存到设备上，断网也能玩。iPad / iPhone 可以用 Safari 的「分享 → 添加到主屏幕」。

整个游戏就是一个 `index.html`，CSS 和 JS 都写在里面，不引用任何第三方资源。
